# متابعة وضعية الموظفين — تطبيق يعمل دون اتصال بالإنترنت

تطبيق ويب (PWA) مجاني لتتبع الوضعية الحالية للموظفين: الرخص، التقاعد، التوقيف…
يعمل **دون اتصال بالإنترنت** على الهاتف (أندرويد وآيفون) وعلى الحاسوب.

- **لا خادم، لا حسابات، لا إعلانات، لا أدوات تتبّع.**
- كل البيانات تبقى في ذاكرة الجهاز فقط (IndexedDB)، ولا تُرسل إلى أي مكان.
- الوضعية الحالية **لا تُخزَّن أبدًا**: تُحسب من تاريخ اليوم في كل مرة.

---

## الخصوصية والبيانات

- سجلات الموظفين بيانات شخصية: لا تُنسخ إلى المستودع، ولا إلى صفحة المشروع، ولا إلى أي ملف مرفق.
- المستودع يحتوي **الكود فقط**. الملفات المستبعدة عن الرفع محددة في `.gitignore`:
  كل `*.csv` (عدا `sample-fake.csv` المصمَّم للتجربة)، وكل `*.json`، وكل `*.xlsx`.
- الملف المرفق `sample-fake.csv` يحتوي بيانات **تجريبية وهمية بالكامل** (أرقام مهنية بادئة `FAKE-`)، ويُستخدم لتجربة الاستيراد.
- التصدير والنسخ الاحتياطي يتمان داخل الجهاز (تنزيل ملف إلى مجلد التنزيلات).

---

## التثبيت على الهاتف

التطبيق يحتاج رابطًا يعمل بـ HTTPS (الرابط المحلي `localhost` مقبول أثناء التجربة).

### أندرويد (Chrome)
1. افتح رابط التطبيق في Chrome.
2. اضغط ⋮ (القائمة) ← **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
3. سيُضاف أيقونة التطبيق ويفتح كتطبيق مستقل بخلفية سوداء.

### آيفون (Safari)
1. افتح رابط التطبيق في Safari.
2. اضغط زر **المشاركة** ← **إضافة إلى الشاشة الرئيسية**.
3. اضغط الأيقونة: سيفتح بملء الشاشة (بدون شريط المتصفح).

### الحاسوب (Chrome / Edge)
1. افتح الرابط.
2. أيقونة التثبيت في شريط العنوان، أو القائمة ← **تثبيت صفحة الويب**.

---

## أول تشغيل: رمز القفل (PIN)

- عند أول فتح يُطلب منك إنشاء رمز من **4 أرقام على الأقل**.
- **تحذير مهم:** لا يوجد أي استرجاع للرمز. إذا نسيته فستفقد البيانات المحفوظة في الجهاز إلى الأبد — احفظه في مكان آمن خارج الهاتف.
- القفل يعود تلقائيًا بعد **دقيقتين من عدم الاستعمال**.
- يمكن تغيير الرمز من **إعدادات ← تغيير رمز القفل**.

---

## التحديث

- عند صدور نسخة جديدة يظهر شريط **«يتوفر إصدار جديد»** داخل التطبيق.
- اضغط **تحديث الآن** ويعيد التطبيق تحميل نفسه؛ كل الملفات محفوظة مسبقًا في الذاكرة المؤقتة فيعمل دون اتصال بعدها.
- من أجل ذلك، عند تغيير أي ملف يجب رفع رقم `VERSION` في `sw.js`.

---

## النسخ الاحتياطي والاسترجاع

من **إعدادات**:

1. **تنزيل نسخة (JSON)** — يحفظ كل شيء: الموظفين، الصور، السجلات، الأنواع والتسميات.
2. **تشفير النسخة بكلمة سر** (اختياري): PBKDF2-SHA256 + AES-GCM داخل المتصفح.
3. **استرجاع من الملف**: اختر النسخة (وأدخل كلمة السر إن كانت مشفّرة) — تُستبدل البيانات الحالية بالنسخة.
4. **تنزيل CSV** — نسخة جدولية بترميز UTF-8 وفاصلة `;` تفتح مباشرة في Excel.

تنبيه: إن لم تُنشأ نسخة احتياطية منذ **30 يومًا** يظهر تنبيه في أعلى الشاشة.
زر **مسح كل بيانات الموظفين** يطلب تأكيدين قبل الحذف النهائي.

---

## استيراد الموظفين من CSV

1. جهّز ملفًا بترميز UTF-8، السطر الأول عناوين الأعمدة، والفاصلة `;` أو `,`.
2. الأعمدة المقبولة (بأسماء عربية أو فرنسية أو إنجليزية): الرقم المهني، رقم التأجير، الاسم العائلي، الاسم الشخصي، الرتبة، الصفة، المصلحة، القسم، تاريخ الالتحاق بالعمل، تاريخ الازدياد، العنوان، الهاتف، الوضعية العائلية.
3. من **استيراد CSV** اختر الملف. الموظف الموجود بنفس الرقم المهني يتم **تحديثه** ولا يُنشأ سجل مكرر، ويظهر تقرير بالأسطر المتجاوَزة.
4. جرّب الملف المرفق `sample-fake.csv` (بيانات وهمية).

## التشغيل محليًا للاختبار

```bash
# خادم محلي (الـ service worker يعمل على localhost)
node tools/serve.js          # http://localhost:8080
# أو
python -m http.server 8080

# توليد الأيقونات (بدون أي مكتبات خارجية)
node tools/make-icons.js
```

اختبارات آلية (تحتاج Chrome محليًا ومكتبة `puppeteer-core`):

```bash
npm install puppeteer-core
node tools/e2e.js           # يشغّل خادمًا محليًا ويوقفه تلقائيًا
```

> `package.json` غير مرفوع (سياسة `*.json` في `.gitignore`)، لذا تُستدعى أدوات
> `tools/` مباشرة عبر `node`.

الاختبارات تغطي قبول المشروع: العمل في وضع الطيران بعد أول زيارة، البحث بالاسم
والرقم، رخصة 30 يومًا وتاريخ العودة، التقاعد بدون تاريخ، تصدير ← مسح ← استرجاع
مع الصور، واستيراد CSV بنقطتان فاصلتان ورؤوس عربية.

## النشر مجانًا على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وادفع الملفات:
   ```bash
   git init
   git add -A
   git commit -m "offline PWA"
   git branch -M main
   git remote add origin https://github.com/USER/REPO.git
   git push -u origin main
   ```
2. في المستودع: **Settings ← Pages ← Source: Deploy from a branch ← `main` / `/ (root)`**.
3. بعد دقيقة يظهر الرابط `https://USER.github.io/REPO/` ببطاقة HTTPS تلقائية.
4. افتح الرابط من الهاتف وثبّت التطبيق كما هو موضح أعلاه.

يُنشر **الكود فقط**؛ لا توجد بيانات داخله. (بديل آخر: Cloudflare Pages — نفس الملفات الثابتة.)

## بنية المشروع

```
index.html              الواجهة (عربية، RTL)
style.css               التنسيق: أسود #000 وأخضر متوهج #39ff14
manifest.webmanifest    ملف التثبيت (lang=ar, dir=rtl, standalone)
sw.js                   الذاكرة المؤقتة + التحديث (VERSION v1.0.0)
icons/                  192، 512، وmaskable (توليد محلي بـ tools/make-icons.js)
js/app.js               نقطة البداية: الحالة، التنقل، القفل، التحديث
js/db.js                IndexedDB + التخزين الدائم
js/status.js            حساب الوضعية الحالية وتاريخ العودة
js/search.js            البحث + التطبيع العربي
js/csv.js               استيراد/تصدير CSV
js/backup.js            نسخ احتياطي واسترجاع (مع تشفير اختياري)
js/pin.js               القفل بالـ PIN (PBKDF2)
js/views/               الشاشات: بحث، تفاصيل، استمارة، استيراد، لوحة، إعدادات
sample-fake.csv         بيانات تجريبية وهمية للاختبار
tools/                  خادم محلي، توليد الأيقونات، الاختبارات الآلية
```

> ملاحظة للمساهمين: `SPEC.md` و `prototype.html` ملفات مرجعية محلية فقط
> (مستبعدة من الرفع عبر `.gitignore`)، وكذلك `package.json` وكل `*.json`.
